NAS 只读恢复工具 · 公用试用版 0.1.3
作者 / Author: cpe87

适用于 Windows 10/11 x64。已包含 Python 运行环境和 FFmpeg 视频校验程序，无需另外安装 Python 或手动选择 FFmpeg。
安装和首次打开不会自动连接 NAS，也不会开始恢复。请自行填写 NAS 信息，核对 SSH 指纹，选择独立输出盘，并先测试 10 个文件。
NAS 仍需开启 SSH，安装有 Python 3、sudo 及 Btrfs 查询工具。程序不会为您在 NAS 数据卷安装软件。
当前为实验版，单文件上限 4 GiB，无自动断线续传。完整解码不等于已证明原始视频时长。暂未通过多型号 NAS 实测。
卸载仅移除安装程序文件，不会删除外部恢复结果或连接 NAS。
第三方许可证与来源位于 _internal/THIRD_PARTY_LICENSES。本版采用从官方源码编译的 FFmpeg 校验版，不启用外部多媒体库；对应源码、编译工具链源码和构建脚本位于 _internal/source/FFmpeg-9.0.2-corresponding-source.zip。程序仍是实验版，尚未完成跨型号 NAS 验证。

Experimental build, Windows 10/11 x64. Python and FFmpeg are included.
Installation and launch never connect to a NAS automatically. Start with the 10-file pilot.
NAS prerequisites: SSH, Python 3, sudo and Btrfs tools. No software is installed on the affected data volume.
4 GiB per-file limit; no automatic reconnect/resume. Full decode does not prove the original recording duration.
This experimental build is not yet validated across NAS models. FFmpeg is built from official source without external multimedia libraries. Its corresponding source, matching toolchain source and build scripts are included under _internal/source/FFmpeg-9.0.2-corresponding-source.zip.
